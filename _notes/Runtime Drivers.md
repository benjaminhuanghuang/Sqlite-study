# Runtime Drivers

- Bun: Use drizzle-orm/bun-sqlite with the built-in bun:sqlite module.

- Node.js 22.5+: Use drizzle-orm/node-sqlite with the native node:sqlite module (DatabaseSync).

- Turso / Edge: Use drizzle-orm/libsql alongside @libsql/client.

- React Native / Expo: Use drizzle-orm/expo-sqlite or drizzle-orm/op-sqlite.

- better-sqlite3（Synchronous）是目前 Node.js 生态中速度最快的 SQLite 3 驱动
